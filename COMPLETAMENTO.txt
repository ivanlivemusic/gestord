🔐 SICUREZZA IMPLEMENTATA
================================================================================

✅ Password Hashing Sicuro
   - PBKDF2-SHA256 con salt (werkzeug.security)
   - Key stretching per resistenza brute-force
   - Sostituito precedente SHA256 semplice

✅ Configurazione Esterna
   - SECRET_KEY da variabile d'ambiente
   - PORT configurabile via environment
   - Fallback sicuro per sviluppo

✅ Thread Safety
   - Lock per connessioni database multi-thread
   - Compatibile con Flask-SocketIO threading mode
   - Prevenzione race conditions

✅ Altre Misure
   - Session-based authentication
   - Input validation (stati ordini)
   - SQL injection protection (parametrized queries)
   - HTTPS via ngrok (automatico)
   - Costanti centralizzate per stati

🚀 COME UTILIZZARE IL SISTEMA
================================================================================

INSTALLAZIONE:
  $ git clone https://github.com/ivanlivemusic/gestord.git
  $ cd gestord
  $ pip install -r requirements.txt

TEST SISTEMA:
  $ python test_system.py

DATI DEMO (Opzionale):
  $ python create_demo_data.py

AVVIO INTERATTIVO:
  $ python start.py
  (Selezionare da menu: Web App, Admin Console, o Kitchen Display)

AVVIO DIRETTO:
  $ python webapp.py          # Web app (porta 5000)
  $ python admin_console.py   # Consolle amministrazione
  $ python kitchen_display.py # Display cucina

CONFIGURAZIONE PRODUZIONE (Opzionale):
  $ export SECRET_KEY="your-secret-key-here"
  $ export PORT=8080
  $ export NGROK_AUTH_TOKEN="your-ngrok-token"

CREDENZIALI DEFAULT:
  Username: cameriere
  Password: password123
